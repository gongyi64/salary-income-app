# salary-income-app
 
給与収入から給与所得控除額と給与所得を計算する、Python / Tkinter製のシンプルなデスクトップアプリです。
 
2025年分・2026年分の年度別ルールを選択して計算できます。
 
---
 
## 現在の安定版
 
現在の安定版では、以下の機能を実装しています。
 
- 給与収入の入力
- 対象年度の選択
  - 2025年
  - 2026年
- 年度別の給与所得控除額の計算
- 給与所得の計算
- 計算結果の画面表示
- 年度別ルールの自動テスト
- 未対応年度のチェック
 
---
 
## 計算の流れ
 
現在のアプリでは、次の流れで計算します。
 
1. 対象年度を選択
2. 給与収入を入力
3. 年度別ルールから給与所得控除額を計算
4. 給与所得を計算
5. 結果を画面に表示
 
基本的な計算は以下です。
 
```text
給与所得 = 給与収入 - 給与所得控除
なお、給与所得控除額が給与収入を上回る場合には、 画面側で給与収入額を上限として扱います。

年度別ルール

rules/

└── rules_2026.py
calculator.py が選択された年度を判定し、 該当するルールファイルの計算関数を呼び出します。

課税所得について
実際の課税所得の計算には、給与所得から基礎控除や社会保険料控除などの所得控除を差し引く必要があります。

概念的には、



給与所得
    ↓
基礎控除
社会保険料控除
その他の所得控除
    ↓
課税所得
となります。

社会保険料控除等を考慮しない簡易的な課税所得計算は、 実際の税額計算と差が生じるため、現在の安定版では実装していません。

基礎控除の年度別自動計算
その他の所得控除
課税所得の計算
所得税の概算
年度別ルールの追加
ただし、給与所得だけを簡単に確認する用途を維持するため、 機能追加によってGUIや計算処理が過度に複雑にならないようにします。

注意事項
このアプリは給与所得等を確認するための簡易計算ツールです。

確定申告、年末調整その他の正式な税務計算を代替するものではありません。

税制改正等により計算ルールが変更される可能性があるため、 実際の申告や税額確認では最新の法令・国税庁資料等を確認してください。
